## Como trabalho

**Eletrônica:** KiCad, esquemas, layout de PCB e preparação de fabricação.  
**Software:** Python, integração embarcada, automação e testes.  
**Prototipagem:** CAD paramétrico, Blender, impressão 3D e peças para montagem e bancada.  
**VR:** integração de dispositivos e avatares com Unity e VRChat.

Procuro manter a ligação entre projeto e uso: documentar revisões, conferir interfaces e encaixes e distinguir o que foi medido, o que é protótipo e o que ainda precisa ser verificado.
